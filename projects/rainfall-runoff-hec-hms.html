Rainfall–Runoff Modelling

HEC-HMS rainfall–runoff modelling for the Gadilam River Basin using GIS-derived terrain, soil and land-use inputs.

Project overview

Study area: Gadilam River Basin, Tamil Nadu. The basin framework was prepared using ArcGIS Pro and HEC-HMS. The project focused on setting up an event-based rainfall–runoff simulation and reviewing the resulting runoff hydrograph and peak discharge within HEC-HMS. A final report, exported maps, presentation and external result tables were not prepared.

Confirmed workflow

01

Terrain and basin delineation

Used ArcGIS Pro and HEC-HMS to delineate the Gadilam River Basin and configure the subbasin and reach network. The terrain input was an ALOS PALSAR-derived 30 m DSM (file: ALPSMLC30_N011E078_DSM.tif).

02

Soil and land-use inputs

Obtained soil and land-use/land-cover (LULC) data from the TNGIS portal. These thematic inputs were used to derive Curve Number (CN) values for the rainfall–runoff model.

03

Configure loss and runoff transformation

Selected the SCS Curve Number method for losses and the SCS Unit Hydrograph method for transforming excess rainfall into runoff response. The HEC-HMS setup used the “No Baseflow” option.

04

Reach routing and rainfall input

Configured Muskingum routing for reaches. Historical rainfall data were used with a one-hour interval. The confirmed simulation window ran from 7 January 2024 at 21:00 to 9 January 2024 at 00:00, with a one-hour computation interval.

05

Run and inspect the simulation

Ran the model in HEC-HMS 4.13 and reviewed the runoff hydrograph and peak discharge in the software. The HEC-HMS project file and associated basin model, meteorologic model and simulation results were saved.

Tools and methods

  • HEC-HMS 4.13
  • ArcGIS Pro
  • ALOS PALSAR-derived 30 m DSM
  • TNGIS soil and LULC data
  • SCS Curve Number loss method
  • SCS Unit Hydrograph transform
  • Muskingum reach routing

Project status and outputs

  • Basin and subbasin framework configured
  • Rainfall–runoff simulation completed
  • Hydrograph and peak discharge reviewed in HEC-HMS
  • HEC-HMS project and model files saved
  • No final technical report, exported map set, result tables or presentation prepared

Results and limitations

The exact peak discharge value is not currently recalled and is therefore not published here. Calibration or validation against observed streamflow has not been confirmed. This page documents the modelling workflow only and does not claim a validated flood forecast.
